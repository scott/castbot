# S07c carry-forwards

Dev databases that migrated through the pre-fix head 37f2bc7 can re-post one approved approval with sent = 0. Production reached schema v13 from the final S07b code, and the 06:03 backup has 0 approval rows. That one-time re-post is not changed in code.

A Cast CLI turn does not hold a guest reload. castbot can see a CLI turn only after it is journaled, so a reload can cut a CLI turn that is still on the machine.

Schema version 14 adds `agent_vms.state_gen` and `approvals.recover_seq`. Replace machine tables stay out of this version.
